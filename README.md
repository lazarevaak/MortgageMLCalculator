# Mortgage ML Calculator

**MortgageMLCalculator** — iOS-приложение на SwiftUI для прогнозирования стоимости недвижимости и расчёта ипотечного кредита.

Проект выполнен в рамках курса **«Разработка интеллектуальных iOS приложений»**

## Описание

Приложение позволяет пользователю ввести параметры недвижимости, и на основе этих данных Core ML-модель прогнозирует стоимость объекта, после чего приложение рассчитывает условия ипотеки: сумму кредита, ежемесячный платёж и переплату. 

## Возможности

* прогнозирование цены недвижимости с помощью Core ML;
* расчёт ипотечного платежа по аннуитетной формуле;
* настройка первоначального взноса, срока кредита и процентной ставки;
* карта для визуального представления;
* проверка корректности введённых данных;
* fallback-расчёт при ошибке ML-модели;
* история расчётов;
* сравнение вариантов недвижимости;
* график изменения платежа в зависимости от срока кредита.
